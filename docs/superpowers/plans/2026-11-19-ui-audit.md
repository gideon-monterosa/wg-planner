# WG Planner: UI/UX audit (T2), 2026-11-19

Read-only audit of the code at `7ced00d`, run with `cf dev` on local D1 with realistic seed data. Viewports: 375×812 and 1280×800, each in light and dark. Contrast ratios are WCAG 2.x, computed from the tokens in `src/web/styles.css`. Line numbers refer to `7ced00d`.

Not covered: the Ideas tab (doesn't exist yet), native select popups, real iOS Safari, screen readers, live 5xx errors, and widths between 768 and 1023 px.

Severity: High 6 · Medium 21 · Low 21.

## Findings

### A. Global shell and theming
1. **High · dark.** Native controls aren't themed: no `color-scheme` is set.
   - The checkbox renders bright white, select options show near-white text on a white popup, and spinners and scrollbars stay light.
   - Fix: `styles.css:3` → `color-scheme: light`, and `color-scheme: dark` in the dark `:root` (`:20`). Add `select option { background: var(--bg); color: var(--fg) }`. In `index.html:6`, add `<meta name="color-scheme" content="light dark">` and a `theme-color` meta for each scheme.
2. **High · dark.** White on the accent is 3.64:1.
   - Fix: add `--accent-fill` and use it for filled backgrounds at `QuickAdd.tsx:68`, `MovingList.tsx:66`, `Overview.tsx:23`, `Rooms.tsx:141`, `People.tsx:76`. `--accent` stays for text: `#5b9ef0` in dark.
3. **Medium · light.** The accent fails as a fill (4.42) and as text (4.23); this hits the active nav tab (`App.tsx:26`) and the flatmates link (`MovingList.tsx:52`).
   - Fix: `--own` and `--accent` → `#1f6fc9` (`styles.css:4,8`).
4. **Medium · both.** Field and chip borders are 1.24/1.37:1.
   - Fix: a `--field-border` token for form controls and chips at `QuickAdd.tsx:34`, `ItemPage.tsx:13-14`, `MovingList.tsx:66`, `Rooms.tsx:49,61,70,136`, `People.tsx:63`. `--line` stays for dividers.
5. **Medium · light.** Placeholders are 3.27:1.
   - Fix: `::placeholder { color: var(--muted); opacity: 1 }`.
6. **Medium · dark.** Red text is 3.64:1.
   - Fix: a `--danger` token replaces `text-red-600` at `QuickAdd.tsx:73,78`, `ItemPage.tsx:79,118,185,216,294`, `Rooms.tsx:76,79,80,132,145`, `People.tsx:41,80`.
7. **Medium · desktop.** The layout is a 576 px column, leaving 55 % empty, and the full-bleed bottom nav puts List at the far left and Overview at the far right.
   - Fix: the desktop top bar (see the recommendations), the nav `md:hidden`, the container `md:max-w-5xl`, `md:pb-8`.
8. **Low.** Focus rings are the browser default.
   - Fix: `:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px }`.
9. **Low · mobile.** The gear is 38×38.
   - Fix: `App.tsx:39` → `inline-flex min-h-11 min-w-11 items-center justify-center`.
10. **Low.** The unknown route is a bare "Not found.".
    - Fix: add an `h1` and a "Back to the list" link (`App.tsx:90`).
11. **Low.** The app's loading and error states are bare.
    - Fix: centre them, use `--muted`, and add `role="alert"` and a Reload button (`App.tsx:101,112`).
12. **Low.** Settings removes the header, and no tab is active.
    - Fix: on desktop, keep the top bar on `/settings` and give the gear `aria-current="page"`.

### B. Moving list
13. **High · all.** The "only you" badge sits inside the truncated span, so long names hide it. A private item then looks shared.
    - Fix: `MovingList.tsx:90-95` → the row is `flex min-w-0 items-center gap-2`, the name goes in its own `truncate` span, and the badge gets `shrink-0`.
14. **Medium · mobile.** Long room headers split the subtotal ("CHF" / "150.–").
    - Fix: `MovingList.tsx:78-80` → the `h2` gets `gap-2 items-baseline`, the name `min-w-0 break-words`, and the price `shrink-0 whitespace-nowrap`.
15. **Medium · mobile.** Filter chips are 30 px tall.
    - Fix: `MovingList.tsx:65` → `min-h-10 px-3.5 py-2`.
16. **Medium · mobile.** QuickAdd is 38 px tall with 14 px text, so iOS zooms on focus.
    - Fix: `QuickAdd.tsx:34` → `text-base md:text-sm min-h-11`, and the button gets `min-h-11`.
17. **Medium.** There's no empty state for filters that match nothing.
    - Fix: when `groups.length === 0`, show "Nothing matches this filter."; an empty group shows "Nothing here yet."
18. **Medium.** The list error is a dead end.
    - Fix: `role="alert"` plus a "Try again" button that refetches items and rooms (`MovingList.tsx:42`).
19. **Low · mobile.** The pill column is ragged.
    - Fix: the price cell `w-24 shrink-0 whitespace-nowrap` (`MovingList.tsx:99`).
20. **Low · copy.** "paid by: not set" reads like a form label, and personal items repeat the payer.
    - Fix: "No payer yet"; skip the payer when `forPersonId !== null`. Capitalise the default person name in `src/worker/auth.ts` (`insertPerson`).
21. **Low.** "Mine" is ambiguous.
    - Fix: rename it to "Just mine".
22. **Low · a11y.** The row's accessible name runs together ("Standing deskonly you").
    - Fix: an `sr-only` ", " before the badge, or `aria-label="only visible to you"`.

### C. Item modal
23. **High · mobile.** The idea star is 20×20, Edit 25×20 and Delete 42×20, only 12 px apart.

24. **Medium · mobile.** Idea prices wrap and titles truncate at about 22 characters.
    - Fix: the price `shrink-0 whitespace-nowrap` (`ItemPage.tsx:144`); the title `line-clamp-2 break-words min-w-0` (`:141`).
25. **Medium · dark.** The sheet blends into the dimmed page (1.11:1).
    - Fix: `ItemModal.tsx:43` → `bg-[var(--surface)] border border-[var(--line)]`; the scrim goes to `bg-black/60` (`:34`).
26. **Medium.** Long item names are clipped in the single-line name input.
    - Fix: an auto-growing `<textarea rows={1}>` (`field-sizing: content`), with price and status under the name on mobile (`flex-col sm:flex-row`) (`ItemPage.tsx:204-211`, `:48`).
27. **Medium.** `/items/abc` makes the id `NaN`, so `useItem` is disabled and the sheet shows "Loading…" forever. A people or rooms error also leaves it loading.
    - Fix: `ItemPage.tsx:311-315` → if `!Number.isFinite(id)`, show not-found; handle `people.isError || rooms.isError`; add "Back to list" next to the not-found message.
28. **Low.** Control heights are inconsistent: selects 35, inputs 38, buttons 34.
    - Fix: `ItemPage.tsx:13` → `min-h-11 py-2`; `:14` → `min-h-10`.
29. **Low.** The ✕ floats over scrolled content.
    - Fix: a non-scrolling header row with a 44 px ✕, and drop `pt-8 md:pt-10` from the scroller (`ItemModal.tsx:62-70`).
30. **Low · mobile.** The "Show to everyone" checkbox is small.
    - Fix: the label gets `min-h-11`; the input `h-5 w-5 accent-[var(--accent)]`.
31. **Low.** With quantity above 1, the per-piece price isn't shown.

32. **Low.** The ideas section has no empty hint.

34. **High · mobile.** Table amounts wrap, and in Spent mode the cells run together.
    - Fix: the numeric cells get `whitespace-nowrap pl-3`; drop the "CHF " prefix in cells and title the column "Total (CHF)"; "Who" gets `break-words` (`PersonBars.tsx:46-56`).
35. **Medium · copy.** The footnote always describes Planned.

36. **Medium · touch.** Bar segment tooltips need hover or focus.
    - Fix: `h-3` → `h-4`, and add `onClick={() => setTip(text)}`, or drop `tabIndex` and rely on the table.
37. **Low.** The legend shows in table view, and its wording doesn't match the rows or tiles.
    - Fix: render the legend only when `!table`, and align its wording with the rows.
38. **Low · light.** The `--unassigned` and `--together` bars are below 3:1.
    - Fix: use the token values above.
39. **Low · mobile.** "Show as table" is about 16 px tall; the toggle is 34 px.
    - Fix: give "Show as table" `py-2 -my-2 px-1`; the toggle `min-h-10 px-3 py-2`.
40. **Low.** Inline `borderColor` styles, unmuted loading text, and an empty track for a zero row.
    - Fix: use `border-[var(--line)]`, `text-[var(--muted)]`, and a 1 px baseline when the total is 0.

### E. Settings
41. **Medium · mobile.** Room rows wrap onto three lines (134 px tall), with Delete alone on the last.
    - Fix: a two-row grid. Row 1: the name at full width. Row 2: the select (`flex-1`), ↑ ↓, and Delete with `ml-auto`. One line from `md:`.
42. **Medium.** Long room names are clipped, at 375 and at 1280.
    - Fix: the name `flex-[2]`, the select `w-40 shrink-0`. Wider desktop cards also help.
43. **Medium · mobile.** People rows clip names and emails.
    - Fix: `People.tsx:37` → `flex flex-col gap-1 sm:flex-row`; the add form's button goes on its own row on mobile.
44. **Medium · touch.** Editable inputs show their border only on hover.
    - Fix: always show `border-[var(--field-border)]`.
45. **Medium · mobile.** Targets are small: arrows 30×34, Delete 63×32, select 31, Add 32, Back 34×36.
    - Fix: `min-h-10` (and `min-w-10` on the arrows) at `Rooms.tsx:49,61,70,76,136,141`, `People.tsx:63,76`, `Settings.tsx:9`.
46. **Low · desktop.** Drag-to-reorder has no affordance.
    - Fix: a ⋮⋮ handle with `cursor-grab`, and a drop highlight.
47. **Low.** The heading sizes are inverted: page `text-lg`, sections `text-xl`.
    - Fix: sections `text-base font-semibold`, page `text-xl`.
48. **Low · copy.** Duplicate room names are allowed silently, and it's not explained that adding a person creates a room.
    - Fix: append "This also creates a room for them." to the People helper text, and warn on duplicate room names.

## Desktop layout recommendations (≥768 px)
1. **Top bar:** sticky, with the bottom border and background. Inner `mx-auto flex h-14 max-w-5xl items-center gap-6 px-6`.
   - Contents: the title, then the tabs List · Ideas · Overview with `aria-current`, then the gear with `ml-auto`.
   - Reuse the `TABS` array for both navs. On `/settings`, keep the bar and mark the gear active.
2. **Bottom nav:** `md:hidden`. The shell gets `pb-20 md:pb-8`. On mobile, the tabs get icons and `min-h-12`.
3. **Container:** `mx-auto max-w-xl md:max-w-5xl md:px-6`, shared by the header and main.
4. **Moving list:**
   - QuickAdd becomes one row at `md:`: name `flex-[3]`, room select `w-56`, price `w-32`, button, `md:flex-nowrap`.
   - Rooms become a card grid: `grid items-start gap-4 lg:grid-cols-2`, each card `rounded-xl border border-[var(--line)] bg-[var(--surface)] p-3`.
5. **Ideas tab:** the same card grid. "Not linked yet" spans both columns (`lg:col-span-2`) at the top, and quick capture is a single row.
6. **Overview:**
   - Tiles: `grid-cols-1 sm:grid-cols-3`, values `md:text-2xl whitespace-nowrap`.
   - At `lg:`, bars and table side by side (`lg:grid-cols-[2fr_1fr]`), or one column capped at `max-w-3xl`.
7. **Settings:** `lg:grid lg:grid-cols-2 lg:gap-8 lg:items-start`. Hide the back arrow at `md:`.
8. **Item modal:**
   - `md:max-w-2xl`, with a 2-column field grid at `md:`. Name, Notes and Ideas span both columns; Room/For, Quantity/Status and Paid by/Own price pair up.
   - Use the `--surface` background with a border.
9. **Hover states:** rows, chips and tabs get `md:hover:bg-[var(--line)]/40`.
